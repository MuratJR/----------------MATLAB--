# 自动控制原理综合可视化分析工作台 (AutoControl Workbench) 使用指南

本工作台是专为《自动控制原理》学习、期末实验与考研自控复习打造的**现代化交互式控制系统分析软件**。现已全面完成**高内聚、低耦合的工程化架构解耦重构**，采用典型环节串联积架构与 LaTeX 高清公式渲染面板，支持环节按需勾选自由组合、正/负反馈自由切换、动态增益联动追踪与四大核心图表分析。

---

## 一、 快速启动方式

在 MATLAB 命令行窗口（Command Window）中直接运行：

```matlab
AutoControlWorkbench
```
程序启动时会自动识别根目录并动态注册子模块路径（`addpath`），无需手动配置 MATLAB 搜索路径。

---

## 二、 工程目录架构设计 (Software Architecture)

为保障工程的可维护性、可测试性与模块独立性，系统彻底废除千行单脚本模式，解耦为清晰的五大子系统：

```
根轨迹/
├── AutoControlWorkbench.m       % 🚀 主程序入口与 GUI 交互控制中枢 (约 450 行)
│
├── core/                        % 🧠 自控原理核心数学与算法计算引擎
│   ├── parseTransferFunction.m  %    系统传递函数解析 (典型环节积/表达式/多项式三合一)
│   ├── calcBreakawayPoints.m    %    实轴分离点与会合点数值求解 (dK/ds = 0)
│   ├── calcImagCrossings.m      %    根轨迹虚轴交点与临界增益求解 (令 s = jω)
│   └── calcNyquistLimits.m      %    奈奎斯特智能抗发散动态视界计算 (过滤无限大奇点)
│
├── plot/                        % 📈 专业图表可视化渲染引擎
│   ├── renderRootLocus.m        %    根轨迹渲染 (分支、零极点、分离点、动态红星极点)
│   ├── renderBodePlot.m         %    Bode 图渲染 (幅频、相频、剪切频率、稳定裕度)
│   ├── renderNyquistPlot.m      %    Nyquist 图渲染 (正频/负频/全频、临界点、单位圆、稳定判据)
│   └── renderStepResponse.m     %    闭环阶跃时域响应渲染 (稳态值、调节带、动态性能指标)
│
├── report/                      % 📝 理论分析与报告生成
│   └── generateAnalysisReport.m %    全指标详细分析报告生成器 (四大核心章节全要素输出)
│
├── presets/                     % 📚 经典教材与工程预设题库
│   └── getPresetLibrary.m       %    案例定义与参数配置数据字典
│
└── utils/                       % 🛠️ 通用辅助工具箱
    ├── poly2str_custom.m        %    多项式降幂系数转标准数学字符串
    ├── formatFactorList.m       %    因式分解聚合格式化 (如 (s+2)^2)
    ├── formatComplexArray.m     %    复数数组字符串格式化
    └── ternary.m                %    三元条件选择辅助函数
```

### 为什么采用这种工程架构？
1. **职责单一 (Single Responsibility)**：界面搭建只管布局与事件监听，算法只管数学计算，绘图只管图表呈现；
2. **极速定位问题**：
   - 根轨迹分离点有疑问？直接打开 `core/calcBreakawayPoints.m`；
   - 奈奎斯特图样式或频率范围调整？直接打开 `plot/renderNyquistPlot.m`；
   - 想新增一套教材经典习题？只需在 `presets/getPresetLibrary.m` 中追加配置；
3. **支持独立脚本与无头测试**：所有 `core/` 下的算法函数均可脱离 UI 在 MATLAB 命令行窗口直接调用，方便编写自动化测试或批处理验证。

## 三、 核心功能与使用特色

### 1. 典型环节串联积输入架构（精准满足自控题型规范）
系统中任意开环传递函数 $G(s)H(s)$ 均可拆解为典型环节的乘积。工作台提供**按需勾选与参数输入卡片**，没有的环节取消勾选即可：

| 典型环节 | 环节传递函数表达式 | 支持的输入规范（支持多环节/多个数并行） |
| :--- | :--- | :--- |
| **① 比例放大环节 $K$** | $K$ | 增益倍数直接填入数值（默认 1.0） |
| **② 积分环节 $\frac{1}{s^\nu}$** | $\frac{1}{s^\nu}$ | 复选框开关；下拉选择型别 $\nu = 0, 1, 2, 3, 4$（从 0 型到 4 型任意重数积分） |
| **③ 一阶惯性环节** | $\prod_{i=1}^{k} \frac{1}{T_i s + 1}$ 或 $\prod_{i=1}^{k} \frac{1}{s + p_i}$ | 复选框开关；支持下拉切换 **尾1型 $[T]$** 或 **首1型 $[极点p]$**；**支持任意数量极点向量**（如 `[-1, 4]` 或 `[0.1, 0.05, 0.02]`，包含 2~N 个惯性环节） |
| **④ 一阶微分/超前环节** | $\prod_{j=1}^{m} (\tau_j s + 1)$ 或 $\prod_{j=1}^{m} (s + z_j)$ | 复选框开关；支持下拉切换 **尾1型 $[\tau]$** 或 **首1型 $[零点z]$**；**支持任意数量零点向量**（如 `[1, 3]` 或 `[0.5, 0.2]`） |
| **⑤ 二阶振荡环节** | $\prod \frac{\omega_{ni}^2}{s^2 + 2\zeta_i\omega_{ni} s + \omega_{ni}^2}$ | 复选框开关；**支持多组振荡环节**，各组间用分号 `;` 分隔：<br>• 双参数标准型 $(\zeta, \omega_n)$：如 `0.5, 4; 0.7, 10`<br>• 三参数多项式 $(a, b, c)$：如 `1, 4, 16; 1, 14, 100` |
| **⑥ 二阶微分环节** | $\prod \frac{s^2 + 2\zeta_{zi}\omega_{nzi} s + \omega_{nzi}^2}{\omega_{nzi}^2}$ | 复选框开关；**支持多组二阶零点**，分号分隔（如 `0.7, 2; 0.5, 8`） |
| **⑦ 纯延迟环节** | $e^{-\tau s}$ | 复选框开关；填入延时时间 $\tau$（秒），底层采用 2 阶 Padé 严格近似 |

> 💡 **环节数量动态统计徽章**：在选配面板底部会实时显示各环节的具体个数统计与开环总阶数 $n$、零点数 $m$（例如：`惯性×2, 微分×1, 振荡×1组 | 阶数: n=4, 零点: m=1, 型别: 0型`），方便核对模型结构！
> 
> 💡 **备用模式**：工作台依然保留了「自由数学表达式模式（如 `10*(s+1)/(s*(s+2))`）」和「多项式系数模式」，可在左侧标签页自由切换！

---

### 2. 📐 LaTeX 高清数学公式实时渲染面板
在右侧主界面顶部常驻 **LaTeX 渲染看板**：
1. **开环传递函数 $G(s)H(s)$**：
   以标准因式分解形式高清呈现，例如：
   $$G(s)H(s) = \frac{K (s+1)}{s (s+4) (s^2 + 4s + 16)}$$
2. **闭环特征方程**：
   实时展开呈现当前增益下的闭环多项式方程：
   $$D(s) \pm K N(s) = s^4 + 3s^3 + 12s^2 + \dots = 0$$

---

### 3. 🔄 反馈极性自由切换
- **负反馈（默认）**：对应闭环特征方程 $1 + G(s)H(s) = 0$，绘制常规 $180^\circ$ 根轨迹，Nyquist 以 $(-1, j0)$ 为临界判据基准。
- **正反馈**：对应闭环特征方程 $1 - G(s)H(s) = 0$，绘制 $0^\circ$ 根轨迹，Nyquist 以 $(+1, j0)$ 为临界判据基准。

---

### 4. 🎛️ 动态增益 $K^*$ 滑块实时联动
- 拖动增益滑块或在微调框中输入数值；
- 根轨迹图上的**红色星标闭环极点**实时沿根轨迹各分支动态移动；
- 左侧状态卡片即时更新**稳定性红绿灯（稳定/临界稳定/不稳定）**、主导极点参数（$\zeta, \omega_n$）以及幅相裕度；
- 阶跃响应曲线同步重绘。

---

### 5. 四大核心图表与全要素看板
1. **根轨迹图（Root Locus）**：
   - 标注开环极点（$\times$）、开环零点（$\circ$）；
   - 算法精确计算并高亮实轴有效分离点与会合点（黄色五角星 $\star$）；
   - 支持一键切换等阻尼比线网格（`sgrid`）；
   - 动态红星实时追踪闭环极点当前位置。
2. **对数频率特性（Bode 图）**：
   - 绘制对数幅频曲线与相频曲线；
   - 标注截止频率 $\omega_c$、相位穿越频率 $\omega_g$、相位裕度 $P_m$ 与幅值裕度 $G_m$（dB）。
3. **幅相特性曲线（Nyquist 图）**：
   - **三档频率范围自由切换**：
     - `正频域 (0 → +∞)`：经典幅相特性主曲线（$\omega \ge 0$），观察低频到高频走向与相位裕度；
     - `负频域 (0 → -∞)`：共轭对称镜像分支（$\omega \le 0$），观察负频率下与实轴对称的轨迹；
     - `全频域 (-∞ → +∞)`：正负频率全闭合轮廓，严谨配合奈氏判据分析绕圈数 $N$；
   - **智能抗发散视界**：彻底解决虚轴极点与积分环节使坐标被撑爆至 $10^{22}$ 的问题，自动框选核心响应区；
   - **快捷视角工具栏**：支持一键切换「🎯 自适应全局」、「🔍 聚焦临界点」、「🔬 放大曲线本体」与「🌐 广域全景」；
   - **单位圆与临界标线**：可自由开关 $|s|=1$ 黄金参考圆，标出负实轴穿越点；
   - **严谨稳定判据解析**：动态计算 $P, Z, N$，推导闭环稳定性充要条件。
4. **闭环时域阶跃响应（Step Response）**：
   - 当前增益下的闭环阶跃响应曲线；
   - 标注稳态基准线与 $\pm 2\%$ 调节带。
5. **综合指标全景看板（Dashboard）**：
   - 输出系统型别（0/1/2型）、误差常数 $K_p, K_v, K_a$、渐近线交点 $\sigma_a$ 与倾角 $\varphi_a$、所有闭环极点（实部、虚部、阻尼比、频率）、时域指标（$t_r, t_p, t_s, \sigma\%, e_{ss}$）及频域裕度。
